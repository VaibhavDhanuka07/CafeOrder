# AI Image Generation Prompts for Madhav Bakers

Use these prompts with DALL-E, Midjourney, Stable Diffusion, or any AI image generator.

## Image Specifications:
- Resolution: 1024x1024 or higher
- Format: JPG or PNG
- Aspect Ratio: 1:1 (square) or 4:3 (landscape)
- Save location: `/public/images/`

## Testing Your Images

After adding images:
1. Restart your dev server (`npm run dev`)
2. Go to the menu page
3. Scroll to see featured products
4. Images should load automatically

If images don't show:
- Check filename spelling (must match exactly)
- Verify files are in `/public/images/` folder
- Check file extensions (.jpg not .jpeg)
- Clear browser cache (Ctrl+Shift+R)
